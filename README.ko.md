# Aiary · 아이어리

계획표와 기록표를 한눈에 보고, 실제 기록에 따라 남은 하루를 조정하는 시간관리 앱입니다. 제가 종이에 쓰던 방식을 휴대폰과 PC에서 쓸 수 있게 만들고 있습니다.

[English](README.md)

![계획과 실제 행동을 위아래로 비교하는 Aiary 모바일 시간표](assets/timetable-demo.png)

한 시간은 10분 칸 여섯 개로 나뉩니다. 계획과 실제 행동을 같은 시간표에서 위아래로 비교하고, 휴대폰에서는 칸을 쓸어 활동을 기록합니다. 타이머를 켰다가 끄는 대신, 지나간 시간을 나중에 기록할 수 있게 했습니다.

## 만든 이유

다른 계획 도구는 직관적이지 않거나 계획을 짜고 관리하는 게 너무 번거로웠습니다. 그래서 전자식 도구보다 종이에 계획표와 기록표를 쓰곤 했습니다.

AI를 다루며 작은 프로그램을 만들어 보다가, 종이에 쓰던 표를 내 방식대로 만들 수 있겠다는 생각이 들었습니다. 계획을 세우는 건 좋아하지만 매번 계획을 잘 지키는 사람은 아닙니다. 계획이 틀어졌을 때 남은 하루를 다시 짜는 수고를 줄이고 싶었습니다.

## 쓰면서 정한 것

- **계획과 실제를 한 화면에 둡니다.** 무엇을 하려 했고 실제로 어떻게 보냈는지 바로 비교하고 싶었습니다.
- **기록은 몇 번의 조작으로 끝냅니다.** 칸을 쓸어 시간을 고르고 활동과 점수를 간단히 남깁니다.
- **바뀌는 건 이후 계획입니다.** 이미 지나간 활동이나 현재 계획은 옮기지 않고, 뒤에 남은 일정만 조정합니다.
- **취침 목표를 지킵니다.** 조정 가능한 활동과 여유 시간을 먼저 사용해 하루가 밀려도 취침 목표를 유지하려고 합니다.
- **인터넷 없이도 씁니다.** 휴대폰에서 계획과 기록이 작동하고, PC 동기화는 추가 기능으로 둡니다.

## 지금 되는 것과 남은 것

휴대폰과 Windows에서 사용할 수 있는 개인용 앱을 만들었습니다. 휴대폰은 오프라인에서 계획과 기록을 처리하고, 같은 Wi-Fi의 PC와 동기화할 수 있습니다. 하루 기록은 노션에 저장해 AI 도구가 참고할 수 있는 형식으로 내보낼 수 있습니다.

아직은 제 생활 패턴에 맞춘 프로토타입입니다. 사람마다 다른 활동 우선순위와 조정 규칙을 설정하는 것, 주중·주말 시간표, 다른 캘린더와의 연동은 더 풀어야 할 문제입니다.

## AI와 함께 만든 방식

AI는 코드 작성과 오류 분석을 도왔습니다. 어떤 불편을 해결할지, 제 생활에서 어떤 규칙이 필요한지 정하고 실제로 써보며 수정 방향을 정한 것은 저입니다. 직접 사용하고 다시 고치는 과정을 반복해 앱을 만들고 있습니다.

## 이 저장소에 포함된 것

이 저장소는 프로젝트 소개와 화면 이미지로 구성한 포트폴리오입니다. 앱의 소스 코드나 설치 파일은 넣지 않았습니다. 이전 공개 저장소와 릴리스는 별도로 남아 있어, 이 포트폴리오 저장소를 만든다고 이미 공개된 파일이 회수되는 것은 아닙니다.
